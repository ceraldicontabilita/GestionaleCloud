# Validazione rapida pagine GestionaleCloud

Usa questo file in modo semplice: per ogni pagina marca solo una cosa:

- SÌ = la logica è corretta
- NO = ci sono errori / incoerenze
- MODIFICA = va corretta o spiegata meglio

Scrivi anche una nota breve se serve.

---

## Istruzioni

Per ogni riga:

- lascia il box selezionato
- aggiungi una nota breve solo se serve
- non scrivere lunghe spiegazioni: basta una riga per pagina

Esempio:

- [ ] 01 - Login | SÌ | NO | MODIFICA | Nota: ok, accesso pubblica + login richiesto

## Se vuoi rispondere ancora più velocemente

Puoi usare questa versione compatta:

- 01 Login = SÌ / NO / MODIFICA
- 02 Gestione riservata = SÌ / NO / MODIFICA
- 03 Dashboard = SÌ / NO / MODIFICA
- ...

Oppure puoi semplicemente riportarmi un elenco tipo:

- 03 Dashboard = MODIFICA: aggiungere alert contabili
- 12 Verbali noleggio = SÌ
- 40 Coerenza POS = NO: serve chiarimento su accrediti e commissioni

Questo formato è molto facile da usere e da convertire in correzioni definitive.
