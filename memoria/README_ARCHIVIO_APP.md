Il 17/09/2026 la memoria di progetto è stata unificata: l'unico file di regole
è `CLAUDE.md` alla radice del repository. Questa cartella conserva i documenti
dei repository originali, che non vengono più deployati e servono solo come
storia e consultazione.

| Cartella | Proviene da | Cosa contiene |
| --- | --- | --- |
| `hr/` | `ceraldicontabilita/AppDipendenti` | Memoria storica del portale dipendenti e istruzioni dei modelli di contratto. |
| `lotti/` | `ceraldicontabilita/Lotti` | Regole permanenti del titolare, PRD, changelog `memory/STATO.md`, audit, design handoff, skill riusabili. |
| `menu/` | `ceraldicontabilita/Menu` | Ricerca allergeni del menu (obbligo di legge) ed esiti di collaudo. |

Le regole vive sono state assorbite in `CLAUDE.md`. Se un documento qui dentro
dice il contrario, vince `CLAUDE.md`: questi file raccontano com'erano le cose
alla loro data.
